ASSIGNMENT 08 · API REFERENCE

Student records,
one simple API.

A REST API for creating, finding, updating, and removing student records.

API hosting setup The API runs on Render; GitHub Pages hosts this documentation.
API BASE URL Set this to your Render service URL
Create the Render service using the README setup steps.

ENDPOINTS

Student operations

JSON REST API
POST/api/studentsCreate a student

Add a student with a name, unique roll number, department, and marks from 0–100.

{
  "name": "Aisha Sharma",
  "rollNumber": "CS-2024-018",
  "department": "Computer Science",
  "marks": 88
}
SUCCESS RESPONSE 201 Created
GET/api/studentsList all students

Returns every student. Add ?department=Computer%20Science to filter by department.

SUCCESS RESPONSE 200 OK
GET/api/students/:idGet one student

Find a student by the MongoDB document ID.

SUCCESS RESPONSE 200 OK
PUT/api/students/:idUpdate a student

Update one or more student fields. The new values are validated before saving.

{ "marks": 94 }
SUCCESS RESPONSE 200 OK
DELETE/api/students/:idDelete a student

Permanently removes the matching student record.

SUCCESS RESPONSE 200 OK
GET/api/healthCheck API status

Returns the API and MongoDB connection status. Render uses this endpoint as its health check.

SUCCESS RESPONSE 200 OK

RESPONSE CODES

400 Invalid input or student ID404 Student or route not found409 Duplicate roll number500 Unexpected server error
